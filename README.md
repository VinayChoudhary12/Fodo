# 🍔 Foodie - Food Ordering App

## 📌 Overview

Foodie is a modern and responsive food ordering web application built using React.js. The application allows users to browse food items, search recipes, filter foods by categories, add items to a cart, manage quantities, and place orders through a clean and user-friendly interface.

This project was developed to strengthen my frontend development skills and gain hands-on experience with React ecosystem tools such as Redux Toolkit, Context API, API integration, and Tailwind CSS.

---

## 📸 Features

* 🍽️ Browse food recipes and meals
* 🔍 Real-time search functionality
* 🏷️ Filter food items by category
* 🛒 Add items to cart
* ➕ Increase item quantity
* ➖ Decrease item quantity
* ❌ Remove items from cart
* 💰 Automatic subtotal, taxes, and total calculation
* 📱 Fully responsive design
* 🎨 Modern UI with Tailwind CSS
* 🔔 Toast notifications using React Toastify
* ⚡ State management using Redux Toolkit

## 📦 Installation

Clone the repository:

```bash
git clone <your-repository-link>
```

Navigate to the project folder:

```bash
cd foodie
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
